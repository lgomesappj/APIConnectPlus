# APIConnectPlus

APIConnectPlus enables real-time, cloud-based API-based integration across microservices, utilizing Node and Gateway architecture.

With APIConnectPlus, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/APIConnectPlus.git`
2. `cd APIConnectPlus`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
